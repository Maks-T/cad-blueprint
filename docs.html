cad-blueprint

Лёгкий параметрический 2D-движок чертежей для конфигураторов: слои со штриховками, стили текста и размеров по ГОСТ, примитивы, размеры, блоки, видовые экраны. Экспорт в SVG и DXF, импорт DXF, компактный JSON для БД, просмотрщик с зумом и мост к Three.js.

Установка

pnpm add cad-blueprint
pnpm add three   # только если нужен cad-blueprint/three

Быстрый старт

import { CadDocument, CadPath, polygon, insert, dimLinear, dimChain, renderSvg, exportDxf, stringifyDocument } from 'cad-blueprint';

const doc = new CadDocument({ gost: true, settings: { scale: '1:10' } }); // шрифт, текст и размеры по ГОСТ
doc.layers.create('Контур', { color: '#0f172a', lineWeight: 0.5 });
doc.layers.create('Размеры', { color: '#047857', lineWeight: 0.18 });

const tread = CadPath.start(0, 0).right(300).up(40).left(300).close().filletAll(5).build();
doc.blocks.define('Ступень', [polygon(tread, { layer: 'Контур' })]);

doc.addSheet('Лестница', [
  ...[0, 1, 2, 3].map((i) => insert('Ступень', [i * 280, i * 170])),
  dimChain([[0, 0], [280, 0], [560, 0], [840, 0]], { offset: -120, layer: 'Размеры' }),
]);

const svg = renderSvg(doc);           // строка <svg>, размеры в мм бумаги
const dxf = exportDxf(doc);           // DXF R2007, UTF-8
const json = stringifyDocument(doc);  // компактный JSON для БД

Оси, углы, единицы

  • Геометрия в единицах модели (settings.units, по умолчанию мм). Ось Y вверх (coordinateSystem: 'cartesian') или вниз ('screen').
  • Углы в градусах, против часовой стрелки в числовой плоскости, как в DXF. Это касается дуг, вставок и видовых экранов.
  • Высота текста, стрелки и толщины линий задаются в мм бумаги: при масштабе 1:10 текст 3,5 мм остаётся 3,5 мм на листе.
  • Все объекты неизменяемые (frozen). Изменение означает новый объект: sheet.replace(id, entity).

Слои и стили

doc.layers.create('Сечение', { color: '#1e3a8a', lineWeight: 0.5, hatch: 'steel-45' });
doc.layers.create('Оси', { color: '#dc2626', lineWeight: 0.18, lineType: 'dashdot' });
doc.layers.create('Сетка', {
  hatch: createHatchStyle({ families: [{ angle: 45, spacing: 3 }, { angle: 135, spacing: 3 }], background: '#f0fdfa' }),
});
doc.layers.update('Оси', { visible: false });

doc.dimStyles.update('GOST', { terminatorType: 'tick', textPosition: 'above', textOrientation: 'aligned' });

Штриховки: steel-45, board-45, concrete, wall-45 и свои через createHatchStyle. Объект с fill: 'hatch' берёт штриховку своего слоя. Засечки размеров: arrow-closed, arrow-open, tick, dot, circle, none.

Примитивы и CadPath

line([0, 0], [100, 0], { layer: 'Оси' });
rect(0, 0, 300, 200, { cornerRadius: 20, fill: 'hatch' });
circle([50, 50], 20);
arc([0, 0], 70, 20, 240);                  // центр, радиус, начальный и конечный угол
arcThrough(a, b, c);                      // дуга по трём точкам
ellipse([0, 0], 110, 65, { rotationDeg: 25 });
polyline(points); polygon(points, { holes: [hole] });
spline(points, { degree: 3 }); bezier(controlPoints); fitBezier(throughPoints);
text([0, 0], 'Подпись', { height: 3.5, anchor: 'middle-left' });
mtext([0, 0], 'Строка 1\nСтрока 2', { height: 3.5 });
breakLine(a, b, { waves: 3 }); zigzagBreakLine(a, b);  // линии обрыва ГОСТ 2.303

CadPath строит контуры «черепашкой» со скруглениями и фасками. Результат подходит для polygon и polyline:

const profile = CadPath.start(0, 0)
  .right(80).up(60).left(25).down(18).left(30).up(18).left(25)
  .close().filletAll(4).build();

CadPath.start(0, 0).right(700).up(120).polar(220, 135).left(200).fillet(40).close().build();
CadPath.start(0, 0).right(80).arcTo(180, 200, { tangent: true }).build();

Размеры и выноски

dimLinear(a, b, { offset: -60 });                     // горизонтальный по умолчанию
dimLinear(a, b, { direction: 'vertical', offset: 40 });
dimAligned(a, b, { offset: -30 });                    // вдоль отрезка
dimChain([p0, p1, p2, p3], { offset: -70, texts: [null, '<> (шаг)', null] });
dimBaseline(p0, [p1, p2, p3], { offset: -150 });
dimAngular(vertex, a, b, { radius: 110 });
dimDiameter(center, r, { angleDeg: 35 }); dimRadius(center, r, { angleDeg: -45 });
leader([[600, 60], [780, 220]], 'Сталь Ст3сп, t = 8 мм');

<> в тексте подставляет измеренное значение. Если текст не помещается между засечками, он выносится наружу автоматически.

Блоки и видовые экраны

doc.blocks.define('Профиль', [polygon(profile, { layer: 'Сечение', fill: 'hatch' })], { description: '80×60' });

insert('Профиль', [1150, 0], { scaleX: -1, rotationDeg: 90, layer: 'Оси' }); // объекты слоя «0» берут слой вставки

viewport([insert('Профиль', [0, 0]), dimLinear([0, 0], [80, 0], { offset: -14 })], {
  position: [150, -560],   // где экран стоит на листе
  target: [40, 30],        // какая точка модели в центре
  scale: '1:2',
  clip: { minX: -20, minY: -32, maxX: 112, maxY: 72 },
  frame: true,
  title: 'Узел А (1:2)',
});

Внутри экрана тексты и стрелки считаются по его масштабу, поэтому на бумаге они такие же, как снаружи.

Документ и листы

const doc = new CadDocument({ gost: true, settings: { scale: '1:20', annotationScale: 'auto', padding: [12, 16] } });

sheet.add(e1, e2); sheet.remove('id'); sheet.replace('id', e); sheet.find('id');

doc.context();   // контекст рендера для своих рендереров и габаритов
entitiesBounds(sheet.entities, doc.context());

SVG

renderSvg(doc, { sheet: 'facade', background: '#fff' });    // size: 'paper' | 'none' | { width }
renderSvg(doc, { hiddenLayers: 'hide' });                    // скрытые слои с display:none

Блоки выводятся через <symbol>/<use>, штриховки через <pattern>. Текст в зеркальных вставках остаётся читаемым (как MIRRTEXT=0).

DXF: экспорт и импорт

exportDxf(doc, { sheet: 'facade' });                  // R2007, UTF-8, true color
exportDxf(doc, { version: 'R2000' });                 // для старых программ, кириллица как \U+XXXX

const { block, layers, warnings, fileUnits } = importDxf(fileBytes, { name: 'Профиль', fill: 'hatch', basePoint: 'min' });
for (const l of layers) if (!doc.layers.has(l.name)) doc.layers.create(l.name, l);
doc.blocks.add(block);
doc.addSheet('Импорт', [insert('Профиль', [0, 0])]);
Размеры в DXF пишутся разложенными (LINE, SOLID, TEXT), видовые экраны блоками _VIEWPORT<n> без обрезки. Импорт: LINE, POINT, CIRCLE, ARC, ELLIPSE, LWPOLYLINE, POLYLINE, SPLINE, SOLID, TEXT, MTEXT, INSERT. Единицы берутся из $INSUNITS, вложенные замкнутые контуры становятся вырезами.

Вьюпорт

import { CadViewer } from 'cad-blueprint/viewer';

const viewer = new CadViewer(container, doc, {
  sheet: 'facade', toolbar: false, background: 'transparent', paper: '#fff', fileName: 'order-42',
});
viewer.setSheet('plan');
viewer.setDocument(newDoc, { keepView: true });    // пересборка без сброса зума
viewer.setLayerVisible('Оси', false); viewer.isolateLayer('Контур'); viewer.showAllLayers();
viewer.fitToView(); viewer.zoomIn(); viewer.zoomOut();
viewer.downloadSvg(); viewer.downloadDxf(); viewer.downloadVcad();
viewer.on((e) => {
  if (e.type === 'select') console.log(e.id, e.layer, e.point);  // клик по объекту с id
  if (e.type === 'view') console.log(e.zoom);
});
viewer.destroy();

Колесо зумирует к курсору, перетаскивание двигает вид, двойной клик вписывает. На сенсорных экранах работает щипок. Источником может быть документ, компактный JSON или байты .vcad.

В Filament / Alpine: x-init="CadBlueprint.mountCadViewer($el, @js($record->drawing_json), { toolbar: true })" и wire:ignore на контейнере.

Three.js: 3D и разрезы

import { blockToExtrudeGeometry, sectionObject, sectionToBlock } from 'cad-blueprint/three';
import { Mesh, Plane, Vector3 } from 'three';

const mesh = new Mesh(blockToExtrudeGeometry(doc.blocks.require('Профиль'), { depth: 400 })); // вырезы → holes

const section = sectionObject(scene, new Plane(new Vector3(0, 0, 1), -180)); // плоскость Z = 180
doc.blocks.add(sectionToBlock(section, 'Разрез А-А', { layer: 'Сечение', fill: 'hatch' }));
sheet.add(insert('Разрез А-А', [0, 0]));

section.loops содержит замкнутые контуры в координатах плоскости, section.basis задаёт её начало и оси. Для нормали (0, 0, 1) ось X сечения совпадает с X мира, Y с Y мира. В демо красную плоскость можно таскать мышью: при каждом сдвиге сечение пересчитывается и лист «3D-разрез» перестраивается.
